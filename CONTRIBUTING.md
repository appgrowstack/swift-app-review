# Contributing

Thanks for taking the time to look at this package.

This repository is a one-way copy. The package is developed in a private monorepo and each release
is copied here with its tag, so changes made here would be overwritten.

## Reporting a problem

Open an issue with the smallest example that reproduces it, the Swift and Xcode versions you're
on, and the platform you're targeting. A failing test is the clearest possible report.

Pull requests are not accepted. If you have a fix in mind, describe it in the issue.

Versions follow [SemVer](https://semver.org) with bare tags (`1.2.3`, no `v`). While the major
version is 0, a breaking change bumps the minor version.
